# Harness Guard

Host-плагин DSH: ограждение инструментов решениями harness.

Проверяет каждый вызов инструмента до исполнения и запрещает то, что нарушает
политику проекта: границы роли, `allowed_files` активного брифа, защищённые пути
(политика, схемы, состояние, evidence).

Права берутся из `.harness/guard-scope.json`, который публикует управляющий
процесс при диспетче и снимает при вердикте или по таймауту. Агент не может
расширить себе область: файл защищён политикой.

Отказ возвращается строкой вида `R-WORK-1: src/b.py вне allowed_files брифа` и
попадает в результат инструмента как ошибка.

Настройка (необязательно):

* `HARNESS_ROOT` — корень проекта с `policies/policy.json`;
* `HARNESS_ROLE` — роль по умолчанию, если активной области нет;
* `HARNESS_ALLOWED_FILES` — JSON-список разрешённых путей для headless-прогонов.

Ядро (автомат, бюджет, вердикты, коммит) остаётся в Python: плагин отвечает
только на вопрос «можно ли это действие».
