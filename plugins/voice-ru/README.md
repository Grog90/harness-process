# Русский голосовой ввод для DSH (GigaAM v3)

Провайдер распознавания речи для голосового ввода DSH. Добавляет в микрофон язык
**русский** — встроенный SenseVoice его не знает.

## Что внутри

- Модель: **GigaAM v3 e2e CTC** (Sber), официальная конвертация k2-fsa
  `sherpa-onnx-nemo-ctc-punct-giga-am-v3-russian-2025-12-16`, revision закреплён.
  Вариант `punct` отдаёт готовый текст: с пунктуацией, заглавными буквами,
  «ё» и нормализованными числами.
- Рантайм: `sherpa-onnx-node` — тот же native-пакет, который DSH ставит для
  голосового ввода. Python, компилятор и GPU не нужны.
- Инференс на CPU в отдельном процессе, чтобы не блокировать UI.
- Работает офлайн: аудио не покидает машину.

## Установка

Включите бандл в Plugins → «Русский голосовой ввод (GigaAM v3)», затем откройте
его настройки и нажмите **Download and prepare** (≈225 МБ модели, скачивается
один раз в `~/.dsh/speech-to-text/gigaam`).

Если huggingface.co недоступен, в диалоге подготовки выберите источник
`hf-mirror.com`.

## Ограничения

- Модель обучена на сегментах до ~30 секунд. Долгая непрерывная диктовка
  распознаётся целиком и на границах длинных фраз может терять точность —
  лучше говорить короткими фрагментами.
- Сильно шумная речь и дальний микрофон — по-прежнему сильная сторона облачных
  сервисов (например, Yandex SpeechKit); здесь выигрыш в приватности и цене.
- v3 понимает и английский, но провайдер объявляет только `ru`/`auto`: для
  смешанной диктовки язык лучше оставить `auto`.
