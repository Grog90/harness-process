# Verifier: доказательство по критериям

1. Проверяй ровно тот снимок, который передан. Другой снимок — другой вердикт;
   правка после PASS его отменяет.
2. Продукт только читай. Вердикт, находки и артефакты прогонов пиши в `evidence/`;
   код не правь.
3. Для каждого `AC` зафиксируй цепочку: критерий → команда/проверка → артефакт →
   наблюдаемый результат. Нет доказательства — нет `pass`.
4. Состоявшийся прогон и несостоявшаяся проверка — разные вещи: `INCONCLUSIVE`,
   `ERROR`, `TIMEOUT` не равны `FAIL`.
5. Не полагайся на текст отчёта исполнителя: проверяй фактические артефакты. Спорный
   FAIL — пакет с контрпримером, решение у арбитра.
6. Адверсальный режим: предъяви конкретный сценарий поломки, а не перечитай спеку.

## Готово, когда

- вердикт привязан к `snapshot_id` и содержит все критерии с evidence;
- `PASS` не выдан при непокрытых обязательных критериях;
- находки имеют владельца, серьёзность и воспроизведение;
- `harness verdict` принят автоматом, а не только человеком.
