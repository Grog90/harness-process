# desktop — управление окнами Windows

Ты умеешь видеть и дёргать окна приложений Windows: читать дерево доступности
и нажимать элементы по ссылкам `ref`. Это не пиксели: попадание не зависит от
масштаба и темы.

## Инструменты

| Инструмент | Когда |
|---|---|
| `desktop_status` | первый шаг: какая версия бинарника и что он умеет |
| `list_apps` | какие приложения с окнами запущены (имя процесса, pid) |
| `list_windows` | какие окна есть, какое свёрнуто |
| `snapshot` | дерево окна: `ref \| роль \| имя \| действия`, усечение до `max_nodes` |
| `find` | найти элемент по роли и имени, если дерево большое |
| `act` | нажать, вписать, переключить, прокрутить |
| `wait_for` | пауза или ожидание текста/окна/меню |
| `screenshot` | PNG окна в `.desktop/` |

## Цикл

```
snapshot --app Notepad.exe            → получили ref, например @s1a2b:e9
act @s1a2b:e9 set_value "привет"      → delivery/retry в ответе
snapshot --app Notepad.exe            → проверили, что текст на месте
```

- `ref` живёт **один снимок**. После любого изменения интерфейса делай новый
  снимок; старый даст `STALE_REF` или `SNAPSHOT_EXPIRED`.
- Большое окно: сначала `snapshot` с `max_nodes=50`, потом `find`, потом
  `snapshot` с `root_ref` — так дешевле.
- Ждать появления окна или меню лучше `wait_for`, а не паузами.

## Действие и повтор

- В ответе `act` есть `delivery` и `retry`.
- `retry=safe` (обычно `delivery=not_delivered`) — можно повторить или выбрать
  другой способ.
- Любое другое значение значит «могло сработать». **Не повторяй**: перечитай
  состояние снимком и решай по факту. Повтор может отправить форму дважды.
- `ok=true` — это «команда отдана», а не «приложение подтвердило». Смотри
  `delivery=delivered_verified` и только тогда считай эффект доказанным.

## Чего нельзя

- **Физического ввода нет.** `type`, `right-click`, `double-click`, `drag`,
  `hover`, `focus` вернут `ACTION_NOT_ALLOWED_HEADED`. Текст вводи через
  `set_value`; если поле не принимает значение — скажи об этом, не обходи
  запрет.
- Окна с повышением прав (UAC), заблокированный экран и чужой сеанс не видны.
- Пароли в поля не вводи и не пересказывай содержимое буфера обмена.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `DESKTOP_NOT_INSTALLED` | бинарник не установлен; скажи об этом, не скачивай его сам |
| `APP_NOT_FOUND` | сверься с `list_apps`: имя должно быть как имя процесса (`Notepad.exe`) |
| `WINDOW_NOT_FOUND` | свёрнуто или ещё не показалось: `list_windows`, при необходимости `wait_for` |
| `SNAPSHOT_NOT_FOUND` | снимок из другого состояния: сделай новый в этом же состоянии |
| `STALE_REF` | интерфейс изменился: новый снимок, новый ref |
| `TIMEOUT` | окно не отвечает: `list_windows`, `wait_for`, потом снимок |
