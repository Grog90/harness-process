# Привычки: запись опыта с условием и весом

Урок — это строка правила без «когда». Привычка знает, **при каком условии** срабатывает,
**сколько раз** подтвердилась, **чем** доказана и **насколько** ей верить. Уверенность
считается из счётчиков, а не вписывается от руки: иначе «проверенное» и «записанное»
неотличимы.

## Это памятка, а не проверка

Запись в `docs/instincts/` ничего не блокирует, не запускается на каждом шаге и не заменяет
тест. Она подсказывает: «похожая задача уже была, вот чем кончилась». Если ошибка ловится
детерминированно — вход известен, ответ однозначен, — привычка не решение: нужна ступень 3
(`policies/rules.json`, хук, тест). Порядок ступеней и цена текста — `docs/LESSONS.md`.

`tools/instincts.py check` проверяет **форму** записи (поля, числа, дату, разрешимость ссылок).
Правдивость текста, актуальность правила и то, что оно действительно работает, не проверяет
ничего: за это отвечает человек-владелец записи.

## Где лежит запись

Один файл — одна запись: `docs/instincts/I-YYYYMMDD-NN.md`, имя файла совпадает с id.
`YYYYMMDD` — дата первого случая. Запись появилась из журнала (`journal/YYYY-MM.md`) и
ссылается на него.

## Поля

| Поле | Что означает | Обязательно |
|---|---|---|
| `Условие` | когда привычка срабатывает: триггер задачи, а не тема | да |
| `Правило` | что делать в этом условии — одной фразой, в императиве | да |
| `Область` | где действует: среда, сервис, каталог | да |
| `Подтверждений` | сколько раз правило сработало; целое `>= 0` | да |
| `Опровержений` | сколько раз не сработало или привело к ошибке; целое `>= 0` | да |
| `Последнее` | дата последнего подтверждения, `ГГГГ-ММ-ДД`; не в будущем | да |
| `Проверка` | как убедиться, что правило сработало: команда или наблюдаемый признак | да (может быть пустым, но тогда нет бонуса) |
| `Доказательства` | непустой список ссылок: `journal:L-XXXXXXXX-NN`, `finding:<id>` или путь к файлу | да |
| `Статус` | `active` — действует, `retired` — снята, но не удалена | да |

Доказательства: `journal:L-…` ищется среди заголовков `## L-…` в `journal/*.md`;
`finding:<id>` — в таблице `findings` базы `.harness/state.db` (только на чтение); всё
остальное считается путём относительно корня репозитория и обязано существовать.

## Формат

```markdown
# I-20261029-03 · keenetic-no-pkill

- **Условие:** на роутере Keenetic скрипт в Entware перезапускает сервис, но конфиг не подхватывается
- **Правило:** не рассчитывать на `pkill` в busybox: убивать через `ps | grep ... | kill`, после `restart` проверять PID
- **Область:** Keenetic, busybox, `/opt/etc/init.d/S99monitoring`
- **Подтверждений:** 1
- **Опровержений:** 0
- **Последнее:** 2026-10-29
- **Проверка:** `ps | grep "[b]lackbox_exporter --config"` до и после restart — PID отличается
- **Доказательства:**
  - journal:L-20261029-03
- **Статус:** active
```

Доказательства можно писать и одной строкой: `- **Доказательства:** journal:L-20261029-03`.

## Уверенность

```
уверенность = подтверждений / (подтверждений + опровержений + 2)
            + 0,2, если «Проверка» непустая
            − 0,3, если «Последнее» старше 180 дней
            результат обрезается в отрезок 0…1
```

Двойка в знаменателе — «правило ещё ничего не заслужило»: одна подтверждённая запись даёт
не единицу, а треть. Пример: 1 подтверждение, 0 опровержений, проверка есть, запись свежая —
`1 / 3 + 0,2 = 0,533`.

Порог показа — **0,5**. `match` показывает только записи с уверенностью не ниже порога:
остальные не удаляются, а ждут подтверждения. Свежая запись с одной пустой «Проверкой»
(`0,333`) в подсказках не появляется — это намеренно.

## Команды

```powershell
python tools/instincts.py check                                  # поля, числа, даты, ссылки; код 1 при отказе
python tools/instincts.py match "перезапустить сервис на роутере" # что уже знаем про эту задачу
python tools/instincts.py explain I-20261029-03                  # поля и расчёт уверенности по шагам
```

`match` сравнивает слова запроса (от трёх букв, без служебных) с «Условием», «Правилом» и
«Областью»; совпадением считается и другая форма слова («перезапустить» ~ «перезапускает»,
«роутер» ~ «роутере»). Нужны слова не меньше чем из половины запроса, иначе запись не
показывается. Порядок — по убыванию уверенности. Флаг `--today ГГГГ-ММ-ДД` фиксирует дату
отсчёта возраста, чтобы проверки не зависели от календаря.

## Чего у привычки нет

- Нет автоматического продления: подтверждения и опровержения вписывает тот, кто применил
  правило и увидел результат. `check` проверит, что это числа, но не что они честные.
- Нет распознавания смысла: `match` — совпадение слов, а не понимание задачи. Промах поиска
  не означает, что привычки нет; смотрите `docs/instincts/` целиком.
- Нет приоритета над проверками: правило в `AGENTS.md`, тест и хук сильнее любой записи здесь.
