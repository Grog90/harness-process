# Security policy

Репозиторий публичный. Пожалуйста, **не открывайте публичный issue** для
уязвимостей.

## Как сообщить

1. Напишите владельцу репозитория приватно (GitHub → профиль `Grog90` → контакт)
   или через GitHub Security Advisory, если он доступен.
2. Укажите версию/коммит, шаги воспроизведения и влияние.
3. Не прикладывайте реальные ключи, токены и персональные данные.

## Что считается уязвимостью

- обход ролей/гейтов harness, подписи коммитов или write-set;
- чтение/запись вне разрешённой области через CLI или плагин;
- подмена evidence/CI-подписи;
- исполнение команды без заявленного намерения.

## Границы

- harness — инструмент процесса, а не песочница; агент с `danger-full-access`
  имеет права пользователя.
- Ключ подписи хранится вне репозитория; утечка ключа = компрометация подписи.
- Секреты в историю не коммитятся; при обнаружении — ротация и очистка истории.

## Поддерживаемые версии

Актуальная ветка `main`. Старые коммиты не поддерживаются.
