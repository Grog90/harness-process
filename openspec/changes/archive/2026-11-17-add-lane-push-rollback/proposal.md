# Предложение: публикация лейна и откат частичного коммита

## Problem

- Лейн сливается локально, но ветку нельзя опубликовать/открыть PR штатно.
- Финализатор коммитит сервисы по одному; если главный коммит падает, сервисные
  коммиты остаются, а evidence уже содержит записи. Работа частично «применена»,
  хотя задача не завершена.

## What Changes

- `harness lane push --task` публикует ветку `harness/<task>` без force;
- `harness lane pr --task --target main` создаёт PR через `gh`, отсутствие `gh` —
  отказ, а не тихий пропуск;
- финализатор запоминает предыдущий HEAD сервисов и при любой ошибке после
  сервисных коммитов делает `reset --soft` (изменения сохраняются), удаляет
  записи `commits`;
- если главный коммит уже сделан, он тоже откатывается `reset --soft`.

## Impact

- Класс риска: **L1** (публикация/откат git-состояния).
- Push/pr требуют `may_commit`; worker не публикует.
- Откат не теряет файлы: `--soft` оставляет изменения в индексе.

## Out of Scope

- Merge/pull-request review и auto-merge.
- Push сервисных репозиториев в их remote (отдельный change).
