# Предложение: вывоз evidence в доверенный каталог

## Problem

CI подписывает evidence cosign, но artifact живёт по срокам GitHub. Нет штатного
способа вывезти evidence на NAS/сетевой диск/шлюз S3 и проверить, что копия не
испорчена.

## What Changes

- `harness evidence export --dest D [--change C]` копирует evidence и пишет
  `evidence-export.json` с sha256 каждого файла;
- `harness evidence verify --dest D` сверяет копию и отказывает при пропаже/порче;
- каталог назначения — ответственность оператора (NAS/S3-gateway/диск);
- без облачного SDK: только файлы, sha256 и json.

## Impact

- Класс риска: **L1** (копирование evidence; источник не меняется).
- Каталог должен быть вне репозитория; совпадение source/dest — отказ.
- Секреты в evidence не появляются: это отчёты/манифесты, не ключи.

## Out of Scope

- Автоматическая загрузка в S3/GCS по API.
- Шифрование каталога назначения (это делает хранилище).
- Retention-политика: её задаёт место хранения.
