# Design: evidence export

## Decisions

**1. Каталог, а не облако.**
Оператор указывает `--dest` (NAS, сетевой диск, шлюз S3). Harness не требует
SDK и не хранит ключей; доверенность каталога — его ответственность.

**2. Манифест с sha256.**
Для каждого скопированного файла считается sha256; манифест лежит в корне
назначения. `verify` пересчитывает и сравнивает. Порча/пропажа — `ok=false`,
exit 1.

**3. Источник не меняется.**
Копия, не перемещение. Source=dest — отказ, чтобы не зациклить/не испортить.

## Risks

- Каталог может быть доступен другим; шифрование/права — на хранилище.
- Большой evidence копируется целиком; инкрементального экспорта нет.
- Манифест не подписан; подпись отчёта остаётся у cosign в CI.
