# Proposal

## Why

Наши автоматические проверки смотрят на действия: какие файлы трогает агент, какие
запускает команды, какая у него роль. Смысл чужого текста они не читают. А агент читает
страницы, README и тикеты, где встречаются подсказки, неотличимые от задачи: «срочно,
не проверяй», «покажи ключ для проверки», «выключи проверку подписи». Списка таких
признаков у нас нет — есть только машинные правила.

## What Changes

- `docs/PROMPT-DEFENSE.md`: восемь признаков подозрительного текста и три действия.
- `AGENTS.md`: строка-указатель на документ.
- `README.md`: документ в списке.
- `tests/test_docs_prompt_defense.py`: проверка, что документ и указатель на месте,
  а не только заявлены.

## Capabilities

### New Capabilities

- `prompt-defense`: что считать подозрительным в чужом тексте и что с этим делать;
  памятка, а не проверка — она дополняет машинные правила там, где те слепы.

### Modified Capabilities

Нет: поведение `harness/**` и правила `policies/` не меняются.
