# Spec Delta

## Purpose

Привычка — это запись опыта: когда срабатывает, что делать, где, сколько раз подтвердилась,
сколько раз нет, откуда взялась. Без веса и доказательства правило неотличимо от догадки.
Дельта задаёт формат, проверку и способ найти нужную привычку по тексту задачи.

## ADDED Requirements

### Requirement: У записи есть поля и доказательства

Каждая запись в `docs/instincts/*.md` ДОЛЖНА (SHALL) содержать поля: «Условие», «Правило»,
«Область», «Подтверждений», «Опровержений», «Последнее», «Проверка», «Доказательства»,
«Статус». «Доказательства» — непустой список ссылок вида `journal:L-XXXXXXXX-NN`,
`finding:<id>` или путь к файлу проекта.

#### Scenario: Запись без доказательства отвергается

- **WHEN** у записи пустой список «Доказательства»
- **THEN** `python tools/instincts.py check` отказывает и называет файл

#### Scenario: Ссылка на несуществующий случай отвергается

- **WHEN** запись ссылается на `journal:L-20260101-99`, которого нет в журнале
- **THEN** проверка отказывает и называет ссылку

### Requirement: Уверенность считается, а не вписывается

Уверенность ДОЛЖНА (SHALL) вычисляться: подтверждения делить на сумму подтверждений и
опровержений плюс два; плюс 0,2 за непустую «Проверку»; минус 0,3, если «Последнее»
старше 180 дней; результат ограничен отрезком от 0 до 1.

#### Scenario: Подтверждения поднимают уверенность

- **WHEN** у двух записей одинаковые поля, но у первой подтверждений больше
- **THEN** уверенность первой выше

#### Scenario: Давняя запись теряет вес

- **WHEN** «Последнее» старше 180 дней
- **THEN** уверенность ниже, чем у такой же свежей записи

### Requirement: Поиск по тексту задачи

`python tools/instincts.py match "<текст>"` ДОЛЖЕН (SHALL) выводить записи, чьи «Условие»,
«Правило» или «Область» содержат слова запроса, с уверенностью не ниже 0,5, по убыванию.

#### Scenario: Находит привычку про роутер

- **WHEN** запрос «перезапустить сервис на роутере»
- **THEN** в выводе есть `I-20261029-03`

#### Scenario: Не находит на чужую задачу

- **WHEN** запрос «собрать релиз»
- **THEN** в выводе нет `I-20261029-03`

## MODIFIED Requirements

### Requirement: Неизвестный тип урока отвергается

Список допустимых типов в `tools/lessons.py` ДОЛЖЕН (SHALL) включать «среда», «домен»,
«поведение», «диагностика». `python tools/lessons.py check` на реальном журнале ДОЛЖЕН
возвращать 0.

#### Scenario: Проверка журнала проходит

- **WHEN** запускается `python tools/lessons.py check`
- **THEN** код возврата 0, отказов нет
