# Предложение: доска как продукт, а не таблица

## Problem

`harness board` выглядит как диагностическая заглушка: 8 равнозначных KPI,
пустая очередь с прочерками, таблица всех change включая `CANCELLED`, нет
фильтров/поиска, светлая тема не совпадает с DSH. В GUI есть только компактная
полоска, полноценной доски внутри DSH нет.

## What Changes

- **DSH-плагин:** полная доска в слоте `main` (`harness-board`) с KPI, очередью,
  фильтрами, поиском и списком задач; кнопка «открыть доску» в компактной панели.
  Данные — тот же `/harness-panel/metrics.json`.
- **HTML-доска:** тёмная тема по умолчанию, sticky-заголовок, 6 приоритетных KPI,
  пустая очередь объясняется текстом, фильтры `Активные/READY/Блок/Архив/Все`,
  поиск, `CANCELLED`/`ARCHIVED` скрыты по умолчанию.
- Тесты: Node-smoke применения клиента (dock+main), фильтры HTML, метрики.

## Impact

- Класс риска: **L1** (представление, без изменения данных и гейтов).
- HTML-доска остаётся самостоятельной; плагин — основной ежедневный вид.
- Требуется перезапуск DSH после обновления client-бандла.

## Out of Scope

- Новые метрики/запись в SQLite; права и приёмка не меняются.
- Полный редизайн мобильной вёрстки.
